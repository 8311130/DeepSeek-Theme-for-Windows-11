【这是什么】

把 DSH 社区的鲸鱼娘素材搬到了 Windows 11 上，两段画面分工明确：

  · 片头（8.06 秒，全屏，带声音）
      霓虹彩线从两侧汇聚 → 全息线稿画出深海女仆装的她
      → 通体白热发亮 → 上色、睁眼、站立定格 → 渐隐沉入桌面

  · 桌面（2.58 秒，无限循环，静音）
      雨夜、绿色代码雨、绿色眼瞳的侧脸特写，缓慢呼吸与眨眼
      这是原皮肤真正给壁纸用的那段，最短、最不抢注意力

  · 只接管两样东西：桌面壁纸 和 登录界面背景（外加那段开机片头）
    系统的深色模式、强调色、任务栏配色、透明效果、主题文件
    一概不碰，你原来什么样就是什么样

  · 托盘程序随时能暂停、停止、还原成你原来的样子


【第一次使用：三步】

  1) WhaleTheme.exe 已经编译好了，可以直接双击，跳过编译
  
     （如果以后改了 WhaleTheme.cs 想重新编译，才需要双击 编译.cmd）

  2) 双击  WhaleTheme.exe
     → 首次运行先解压播放内核，约 15 秒，只此一次
     → 然后全屏播一段 8 秒片头，注意有声音（默认 62% 音量）
     → 片头结束自动渐隐进桌面，右下角出现鲸鱼娘的眼睛图标

  3) 想开机就自动播放：右键托盘图标 → 勾选「开机自启」

  登录界面（可选，需要管理员）：
     右键 tools\安装登录界面.cmd → 以管理员身份运行

  关于 exe 的图标：编译时用 /win32icon 把 assets\whale.ico 打进 exe，
  所以资源管理器里显示的也是那只绿眼睛（16/24/32/48/64/128/256 七个尺寸都在，
  大图标视图会用 256 那张）。改了图标只需重新跑一次 编译.cmd。
  托盘图标是程序运行时从 assets\whale.ico 读的，两者同源。


【片头怎么跳过】

  全屏片头期间，鼠标在任意位置点一下即可跳过。
  跳过是「立刻停音频 + 0.2 秒快速渐隐」，比自然播完更干脆。
  键盘收不到（窗口故意不抢焦点，免得开机时吃掉你的按键）。

  觉得吵？托盘右键 → 取消勾选「片头音效」，片头仍会播但没声音。
  连画面都不想看？托盘右键 → 点「重播片头」以外的入口，或者直接
  用「应用主题（不播片头）」。


【托盘菜单】

  双击图标 → 暂停 或 继续动画（最常用）

  修改动画              弹窗，上传自己的开机动画 / 背景动画（见下一节）
  暂停动画 / 继续动画   画面定格在当前帧
  停止并还原            停掉动画，壁纸/深色/强调色全部回到原状
  重播片头             再走一遍全屏 8 秒片头 + 音效
  应用主题（不播片头）  只把桌面层接上，安静，无声无片头
  开机自启              写/删 HKCU 的 Run 项，勾选状态就是真实状态
  片头音效              关掉 = 片头静音，画面照播
  片头音量              25% / 50% / 75% / 100%
  打开主题文件夹        定位到程序目录
  关于 / 署名           版本 + 素材来源 + 许可证
  退出                  还原 + 结束进程


【换自己的动画：托盘 → 修改动画】

  右键托盘 → 点「修改动画…」，弹窗里分两块：

    开机动画（全屏片头）    [选择视频…] [预览片头] [恢复默认]
    背景动画（桌面循环）    [选择视频…]         [恢复默认]

  · 选完立刻生效，不用重启程序：
      换开机动画 → 点「预览片头」马上能看效果
      换背景动画 → 桌面当场开始循环新视频（壁纸首帧也一起换掉）
  · 只改动你自己那份，assets 里的默认素材一个字节都不会被覆盖
  · 上传的视频会被复制到：
        %LOCALAPPDATA%\WhaleTheme\custom\
    开机动画固定叫 boot.xxx，背景动画固定叫 background.xxx，
    选新的会自动替换掉旧的，原文件（你选的那个）不受影响
  · 随时点「恢复默认」切回鲸鱼娘原版，自定义文件同时删掉

  对素材的建议（不是硬限制，是经验）：
    · 格式：mp4（H.264）最稳，mov/mkv/webm 也能播；
      别的格式程序会先试着探测时长，实在认不出来才提示换格式
    · 开机动画：16:9，5~20 秒；可以有音轨，声音走「片头音效 / 音量」；
      结尾最好自己带淡出，不然切进桌面那一下会有点硬
    · 背景动画：16:9，2~15 秒的无缝循环最耐看；音轨会被静音忽略
    · 大小：单个文件别超过 800MB（弹窗会拦）

  小提示：程序会用自带的 mpv 从视频里自动抽两帧图——
    背景动画的第一帧拿来当壁纸（防止露出旧桌面），
    开机动画的倒数第 0.12 秒那一帧拿来兜住渐隐（防止结尾闪黑）。
    这两张都放在 custom 目录里，跟着你的视频走，不用你管。


【声音规则】

  只用片头视频自带的音轨，没有任何外挂音频文件。
  片头视频没有音轨的话，就是静音，不会去放别的东西。

  这个视频的音频我提前做过处理：结尾 0.5 秒加了淡出，
  所以播完不会有一声"咔"的截断。


【还原：到底会还原什么】

  「停止并还原」依据第一次应用时自动存的快照，只回滚壁纸：

    1. 壁纸路径  → 换回你原来的图片（现在这张：ThemeC\img29.jpg）
    2. 填充方式  → WallpaperStyle / TileWallpaper

  就这两项。因为程序压根没动过深色模式、强调色这些东西，
  所以也不需要还原它们。

  快照在 %LOCALAPPDATA%\WhaleTheme\snapshot.txt
  还原成功后自动删除，下次应用会重新记录。

  ⚠ 登录界面不在主程序的还原范围内——它写在系统目录，必须管理员权限。
    要撤掉请右键 tools\还原登录界面.cmd → 以管理员身份运行。
    主程序点「停止并还原」时，若发现登录背景还在，会弹气泡提醒。


【想换桌面循环视频 / 开机片头（不通过弹窗的做法）】

  现在推荐用「托盘 → 修改动画」来换，能随时切回默认。
  如果你就想永久改掉默认素材（比如做给别人用的整合包），
  也可以直接覆盖文件，程序会自己适配：

  桌面循环：覆盖 assets\whale-loop.mp4
      → 会自动发现它比首帧图新，用自带 mpv 抽第一帧，
        重新生成 assets\desktop-firstframe.jpg（接管壁纸那张兜底图）
      → 按「无限循环 + 静音 + 裁满屏幕」播放

  开机片头：覆盖 assets\boot-intro.mp4，然后必须同时更新
            assets\intro-lastframe.jpg（抓它最后一帧，2560×1440），
            否则片头结束那一瞬间会闪一下黑。

  抓最后一帧的命令（需要 ffmpeg）：
      ffmpeg -sseof -0.12 -i boot-intro.mp4 -frames:v 1 ^
             -vf "scale=2560:1440:flags=lanczos" -q:v 3 intro-lastframe.jpg

  对视频本身的要求（都不是硬限制，只是建议）：
    · 分辨率：越高越好。默认那个 1663×856 在 2560×1440 上要放大 1.54 倍，
      所以看着软。建议换 2560×1440 或更高
    · 比例：16:9 最省事。比 16:9 宽会被左右裁掉，比 16:9 窄会被上下裁掉
      （用的是 panscan 填满，不会变形、不会留黑边）
    · 格式：mp4 / mkv / webm / mov 都行，H.264 最稳
    · 时长：短一点更省资源，2~10 秒的无缝循环最理想


【想换登录界面图】

  覆盖 assets\login-background.jpg，然后重跑一次 tools\安装登录界面.cmd。
  注意：系统硬限制 256KB 以内，超了会被 Windows 静默忽略。


【开机自启是怎么做的（重要）】

  用的不是「启动」文件夹，也不是注册表 Run 键，而是
  **任务计划程序里一个"登录时触发"的任务**，名字就叫 WhaleTheme。

  为什么：实测你这台机器，Run 键拉起的程序比桌面出现晚了 23.5 秒
  （开机 08:20:10 → explorer 08:20:21 → 我们的程序 08:20:44）。
  原因是 Run 键被排在 Steam / EA / Epic / Edge×10 / 百度网盘 / 迅雷 /
  酷狗 / YY / 汽水音乐 这些启动项后面，再加上系统默认约 10 秒的启动延迟。
  换成登录触发的计划任务后，由任务计划服务在登录时直接拉起，早得多。

  ⚠ 所以你现在在「任务管理器 → 启动应用」里**看不到 WhaleTheme** 了，
    这是正常的，不是被关掉了。要看请打开「任务计划程序」，根目录下能找到。

  想关掉：托盘右键 → 取消「开机自启」。它会同时清理计划任务和 Run 键。

  命令行也能设（不弹任何窗口）：
      WhaleTheme.exe --autostart-on
      WhaleTheme.exe --autostart-off

  如果哪天计划任务因为权限原因注册不上，程序会自动退回注册表 Run 键，
  并在 log.txt 里写明用的是哪种方式。


【换新版本 / 改完源码怎么办】

  换新版本：
    1) 右键托盘图标 → 退出（会先还原壁纸）
    2) 用新的 WhaleTheme.exe 覆盖旧文件
    3) 双击 WhaleTheme.exe

  改过源码要重新编译：
    先退出托盘（exe 运行中无法覆盖，编译会报 CS0016 文件被占用），
    再双击 编译.cmd，最后双击 WhaleTheme.exe。

  以后都是直接覆盖 WhaleTheme.exe，没有别的中间文件要清理。


【文件都是干什么的】

  WhaleTheme.cs                 源码，C# 5，想改逻辑都在这里
  编译.cmd                      调系统自带编译器生成 exe（含图标）
  assets\boot-intro.mp4         片头，2560×1440 / 8.06s / 15.1MB / 有音轨
  assets\intro-lastframe.jpg    片头最后一帧，2560×1440，防黑闪用
  assets\whale-loop.mp4         桌面循环，2560×1440 / 2.58s / 5.1MB / 无声
  assets\desktop-firstframe.jpg 循环首帧，当"接管壁纸"，不漏旧图
  assets\login-background.jpg   登录界面那张，170KB（系统限 256KB）
  assets\whale.ico              托盘与 exe 图标（那只绿眼睛，瞳仁里是鲸鱼）
  build\mpv.exe.gz              播放内核压缩包，编译时打进 exe（开源仓库里不含，需自己生成）
  tools\打包播放内核.cmd        把 mpv.exe 压成 build\mpv.exe.gz
  tools\build_check.cmd         只查语法，编到临时目录，不碰正式 exe
  tools\ico_check.cmd           验证 assets\whale.ico 能不能被编译器接受
  tools\make_ico.py             一组 PNG → assets\whale.ico（需要 ffmpeg）
  tools\icon-src\               图标源图，16~256 共 7 个尺寸
  tools\安装登录界面.cmd        写注册表 + 放图片（自动提权）
  tools\还原登录界面.cmd        删图片 + 关开关（自动提权）


【已知限制，先看清楚再用】

  1. 主板 logo 和 Windows 转圈那几秒改不了，那是固件层。
     本主题负责"桌面出现之后"这一段。
  2. 片头源片 1280×720，已超分到 2560×1440 交付；超分不凭空生细节，
     放大看边缘仍偏软。
  3. 桌面循环同理，源片 1663×856 → 超分 2560×1440，边缘也偏软。
     这两条都是素材本身决定的，不是渲染问题；想更清晰就自己换源
     （托盘 → 修改动画，或者直接覆盖 assets 里那两个 mp4）。
  4. 桌面循环只有 2.58 秒，是原作者的"无缝眨眼片段"。
     雨丝位移很小，正常看不出接缝，但盯着一处看能数出节奏。
  5. 桌面动画是挂在一个叫 WorkerW 的系统窗口里的（图标层的下一层）。
     换 Windows 大版本或某些桌面整理软件可能会改这个结构，
     程序会自动在三种宿主里挑，但万一全挑错，桌面会停在静态首帧。
     这时看 log.txt 里有没有「挂载成功 / 20 次重试后仍未挂上」。
  6. 日志在 %LOCALAPPDATA%\WhaleTheme\log.txt，出问题先看它。
